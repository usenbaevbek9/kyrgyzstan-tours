# kyrgyzstan-tours
Bilingual travel website about entertainment in Kyrgyzstan, with 50+ locations across 6 regions.
Live site: https://kyrgyzstan-tours.firebaseapp.com

About

Kyrgyzstan Tours is an ongoing side project that I built together with a friend. It is a "vibe coded" project: we built it with the help of AI tools, guiding the design and content ourselves. The goal is to give visitors a simple place to discover where to go and what to do in Kyrgyzstan.

Features
Information about entertainment and attractions in Kyrgyzstan
50+ locations grouped into 6 regions
Available in two languages: English and Russian
An image for every location
Hosted online and open to everyone
Built with
Hosting: Firebase Hosting
